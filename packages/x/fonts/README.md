# X fonts

These fonts make X cards match the X timeline. The font files and `manifest.json` come from [xeet at commit 095ba15](https://github.com/rauchg/xeet/tree/095ba15/assets/vendor/fonts). The manifest lists each file's family, weight, Unicode ranges, and source.
